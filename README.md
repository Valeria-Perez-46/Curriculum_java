## 📌 Endpoints de la API

| Método | Ruta | Descripción |
| :--- | :--- | :--- |
| `GET` | `/api` | Obtiene la información completa del CV |
| `GET` | `/api?buscar=...` | Consulta filtrada de la información |
| `POST` | `/api` | Registra/crea nueva información en el CV |
| `PUT` | `/api` | Actualiza los datos existentes del CV |
| `DELETE` | `/api` | Elimina un registro del CV |
